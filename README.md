# TOEIC RC 노트

토익 RC 문제풀이 웹앱. 풀이 기록은 각자 기기의 브라우저에만 저장되고, 서버로는 아무것도 보내지 않습니다.

- 문제 2,281개 (Part 5 1,220 · Part 6 432 · Part 7 629)
- 문제마다 해설(정답 단서 → 풀이 → 함정), 보기별 오답 이유, 보기 해석, 핵심 어휘
- Part 6·7은 지문 전체 해석(채점 후 "지문 해석 보기"), 질문 해석, 근거 문장, 패러프레이즈
- 휴대폰에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 연 뒤에는 오프라인에서도 열림
- 기기를 바꿀 때는 설정 → 백업 코드로 옮기기 가능
